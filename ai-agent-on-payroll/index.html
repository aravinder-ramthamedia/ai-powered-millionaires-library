AI Agent: What this page is for

The book teaches you how to run an AI agent the way you would run a new hire, with a rulebook, narrow access, checks, approvals and a kill switch. Those methods outlast any one tool. Tools, plan names, connectors and prices change often, so this page carries the updates. It also lists every ready-to-copy sheet in the book, so you can find the one you need fast.
